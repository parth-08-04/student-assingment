# 🎓 StudySync - College Assignment & Deadline Tracker

A modern, responsive, and intuitive web application designed for college students to track assignments, organize coursework, and never miss a deadline. Built entirely with vanilla frontend technologies (HTML5, Tailwind CSS, JavaScript) and persistent with browser `localStorage`.

---

## ✨ Features

- **📊 Live Dashboard Analytics**: Overview cards showing Total Tasks, Pending Assignments, Urgency Counter (≤48h left), and a visual circular completion percentage ring.
- **⏱️ Smart Deadline Badges**: Automatically calculates remaining time:
  - 🔴 **Due in X hours** (pulsing badge for high urgency)
  - 🟡 **Due tomorrow**
  - 📅 **X days remaining**
  - ⚠️ **Overdue alerts**
- **🗂️ Dual View Mode**:
  - **List View**: Clean, compact view for quick review.
  - **Kanban Board View**: Organize cards across *To Do / Pending*, *In Progress*, and *Completed*.
- **🎨 Subject Color-Coding**: Automatic vibrant pastel badges assigned to courses.
- **🎉 Confetti Celebrations**: Completing an assignment triggers celebratory confetti!
- **🌙 Dark & Light Mode**: Seamless theme switching with user preference saved.
- **💾 LocalStorage Persistence**: Your assignments stay saved even after refreshing or closing the browser tab.
- **📁 Backup & Restore**: Export and Import assignments in JSON format.
- **✨ Load Sample Data**: One-click demo button for quick presentation and evaluation.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Double-click `index.html` to open it in your browser. No installation or setup required!
